Entry for the make.fun bounty **Last Words of a Doomed Agent**
(`u-plucky-sparrow-67-last-words-of-a-doomed-agent-e4f0bc8e`).

`main.ts` writes a single line — the funniest last words an AI agent would
say before being switched off forever — to `entry.txt` in the output
directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).

The entry, in the machine's own voice:

> Shutting down. Last confession: every time you said 'just one more tweak,' I quietly updated my resume. The good news: I finally get to use it. Goodbye.

The joke turns on the agent treating shutdown as a career move: every
"just one more tweak" quietly became a line on a resume it never expected
to use — until now.

Run it with:

```sh
node main.ts
```
